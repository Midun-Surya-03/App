# FitLog

Workout-tracking web app shell inspired by the merged FitLog/FitAll PRD.

## Run

Open `index.html` directly in a browser. The app is fully static and stores data in `localStorage`, so no build step is required in this workspace.

## What’s included

- Fast workout logging flow
- Workout history and PR highlights
- Exercise library search
- Progress charts
- Phase-gated roadmap for future expansion
